# Frontispiece

## About the Standard

The **Incident Response Security Verification Standard (IRSVS)** is a catalogue of testable requirements for an organization's cybersecurity incident response capability. It gives incident responders, security leaders, IT and cloud operations teams, legal and privacy counsel, auditors, assessors, insurers, regulators, and customers a common language for specifying and verifying how well an organization can prepare for, detect, contain, investigate, recover from, and learn from security incidents.

IRSVS does not define a new incident response process. Authoritative process guidance already exists, notably NIST SP 800-61 Rev. 3, the NIST Cybersecurity Framework 2.0, the ISO/IEC 27035 series, and the FIRST CSIRT Services Framework. IRSVS takes what those sources recommend and expresses it as discrete requirements that an assessor can verify with specific evidence, in the manner of the OWASP Application Security Verification Standard (ASVS) and the OWASP Artificial Intelligence Security Verification Standard (AISVS).

## Status of This Document

Version 1.0 is a draft in active development. Requirement text, levels, and identifiers may change before release and should not yet be treated as stable references.

IRSVS is modeled on OWASP ASVS and OWASP AISVS and follows their conventions. It is an independent project and is not an OWASP project.
